# Codex Usage Widget v1.0.0

## Highlights / 亮点

English:

- A draggable Windows percentage ring with edge snapping and hover details for locally observed limits, tokens, cache data, and recent tasks.
- Five interface languages and eight themes, with live language switching from the right-click menu.
- Hidden-console startup through `Start-CodexUsageWidget.vbs`.

中文：

- 可拖拽并自动吸附屏幕边缘的 Windows 百分比圆环，悬停后查看本机观测到的限制、令牌、缓存与近期任务。
- 提供五种界面语言和八种主题，可从右键菜单即时切换语言。
- 双击 `Start-CodexUsageWidget.vbs` 即可启动，不显示终端窗口。

## Download / 下载

Download `CodexUsageWidget-v1.0.0.zip` from the [GitHub release page](https://github.com/libaie/codex-usage-widget/releases/tag/v1.0.0), extract it, and keep the package files together.

从 [GitHub 发布页](https://github.com/libaie/codex-usage-widget/releases/tag/v1.0.0)下载 `CodexUsageWidget-v1.0.0.zip`，解压后保持目录结构不变。

## Requirements / 环境要求

- Windows with Windows PowerShell 5.1 and WPF components. / 带有 Windows PowerShell 5.1 与 WPF 组件的 Windows 系统。
- Local Codex sessions under a discoverable `.codex\sessions` directory. / 本机已有可读取的 `.codex\sessions` 会话目录。
- No third-party runtime or package is required. / 不需要第三方运行时或依赖包。

Start the widget by double-clicking `Start-CodexUsageWidget.vbs`. / 双击 `Start-CodexUsageWidget.vbs` 启动小组件。

## Verification / 验证

Optionally record the archive hash before extraction:

```powershell
Get-FileHash -LiteralPath .\CodexUsageWidget-v1.0.0.zip -Algorithm SHA256
```

After extraction, run the built-in self-test from the package directory:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\CodexUsageWidget.ps1 -SelfTest
```

下载后可先记录 ZIP 的 SHA-256；解压后在目录中运行上述自检。成功时只显示 `自检通过。`。

## Privacy / 隐私

The widget reads the current user's local Codex session records and writes only its preferences and cumulative cache ledger under `%LOCALAPPDATA%\CodexUsageWidget`. It makes no network requests and stores no account credentials.

小组件只读取当前用户的本机 Codex 会话记录，并在 `%LOCALAPPDATA%\CodexUsageWidget` 保存偏好与累计缓存账本。它不联网，也不保存账号凭据。

## Known limitations / 已知限制

- This is an unofficial community tool. Displayed values are best-effort local observations, not OpenAI billing, account, balance, or entitlement data.
- Recognition depends on the local Codex session-file format and may need an update if that format changes.
- This release supports Windows only; macOS and Linux are not supported.

- 这是非官方社区工具。显示数值是对本机 Codex 会话的尽力观测，不是 OpenAI 账单、账户余额或权益数据。
- 数据识别依赖本机 Codex 会话文件格式；格式变化后可能需要更新。
- 本版本仅支持 Windows，不支持 macOS 或 Linux。
