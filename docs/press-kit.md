# Press kit

## 中文长版

Codex Usage Widget 是一个 Windows 桌面悬浮圆环，平时只显示本机观测到的剩余用量，不占太多屏幕。鼠标移上去，可以查看限制窗口、重置时间、令牌、缓存和近期任务；圆环还能拖动，并在靠近屏幕边缘时自动吸附。数据默认来自本机 Codex 会话。程序不调用 Web API，也不上传或同步数据；手动设置文件系统路径后，则从该路径读取。界面提供简体中文、繁体中文、英语、日语和韩语五种语言，可在右键菜单立即切换并记住选择。下载地址：[GitHub Releases](https://github.com/libaie/codex-usage-widget/releases/latest)。

## 中文短版

Windows 悬浮圆环，悬停查看用量详情；默认读取本机会话，不上传或同步数据，支持五种语言。前往 [GitHub Releases](https://github.com/libaie/codex-usage-widget/releases/latest) 下载。

## English

Codex Usage Widget is a floating ring for Windows that keeps locally observed Codex usage in view without crowding the desktop. Hover over the ring to see limit windows, reset times, token and cache totals, and recent task details. The widget is designed for local Codex sessions and reads a configured filesystem path. It does not call Web APIs, upload data, or synchronize it. Its interface supports five languages: Simplified Chinese, Traditional Chinese, English, Japanese, and Korean. Download it from [GitHub Releases](https://github.com/libaie/codex-usage-widget/releases/latest).
