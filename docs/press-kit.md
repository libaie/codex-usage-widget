# Press kit

## 中文长版

Codex Usage Widget 是适用于 Windows 和 macOS 的桌面悬浮圆环。平时只显示本机会话中观测到的剩余用量；悬停后可查看限制窗口、重置时间、令牌、缓存和最近活动任务。圆环支持拖拽和屏幕边缘吸附。程序不调用 Web API，不上传或同步会话数据，也不保存 Codex 凭据。界面支持简体中文、繁体中文、英语、日语和韩语五种语言，并提供八种同步主题。下载地址：[GitHub Releases](https://github.com/libaie/codex-usage-widget/releases/latest)。

## 中文短版

Windows 与 macOS 悬浮用量圆环，悬停查看本机 Codex 用量详情；不上传或同步会话数据，支持五种语言。前往 [GitHub Releases](https://github.com/libaie/codex-usage-widget/releases/latest) 下载。

## English

Codex Usage Widget is a floating ring for Windows and macOS that shows locally observed Codex usage without taking over the desktop. Hover to see limit windows, reset times, token and cache totals, and recent tasks. It reads a configured filesystem path and makes no Web API calls, uploads, or synchronization requests. The interface supports five languages: Simplified Chinese, Traditional Chinese, English, Japanese, and Korean. Download it from [GitHub Releases](https://github.com/libaie/codex-usage-widget/releases/latest).
