# 多语言与 GitHub 开源发布设计

日期：2026-08-10

## 目标

在不改变用量、令牌、缓存和任务筛选逻辑的前提下，为 Codex Usage Widget 增加可切换的外置语言包，并将插件目录作为独立 MIT 开源项目发布到 GitHub。首个公开版本为 `v1.0.0`。

首批语言：

- 简体中文（`zh-CN`）
- 繁体中文（`zh-TW`）
- 英语（`en-US`）
- 日语（`ja-JP`）
- 韩语（`ko-KR`）

## 不在本次范围内

- 不修改用量或缓存令牌统计口径。
- 不提供在线翻译、联网更新或遥测。
- 不建设独立官网或 GitHub Pages。
- 不代替用户向外部社交平台发帖。
- 不在本次顺带重构现有单文件 PowerShell 主程序。

## 语言包结构

语言文件位于 `locales/`，文件名使用固定语言代码，例如 `locales/en-US.json`。每个文件包含元信息和扁平字符串表：

```json
{
  "code": "en-US",
  "nativeName": "English",
  "culture": "en-US",
  "strings": {
    "widget.title": "Usage widget",
    "menu.language": "Language"
  }
}
```

语言加载器只接受包内白名单语言代码、字符串值和预期键名。单个文件限制为 256 KiB；未知键忽略，缺失键从 `en-US` 回退。英语包缺失、损坏或占位符不完整时停止启动，并显示一条内置的中英双语错误信息。语言内容只赋值给已经创建的控件，不参与 XAML 拼接或代码执行。

## 语言选择与持久化

首次启动读取 Windows 当前界面区域：

- 简体中文区域映射到 `zh-CN`。
- 繁体中文区域映射到 `zh-TW`。
- 日语和韩语分别映射到 `ja-JP`、`ko-KR`。
- 其他区域回退到 `en-US`。

右键菜单增加“语言”子菜单。语言名称随当前界面语言显示；切换后立即更新圆环辅助文本、详情卡、任务区、托盘菜单、通知、错误提示和无障碍名称，不需要重启。选择结果写入现有 `preferences.json` 的 `Language` 字段；旧偏好文件没有该字段时继续按系统语言选择。

## 本地化格式

用量和令牌原始数值保持不变，只改变展示：

- 中文继续使用“万、亿”。
- 日语使用“万、億”。
- 韩语使用“만、억”。
- 英语使用 `K、M、B`。
- 日期、数字分组、重置倒计时和时间单位使用对应区域规则。

语言切换不会修改缓存账本、活动任务窗口、主题、位置或提醒门槛。

## 界面实现

静态 XAML 保留结构与命名控件，不插入语言包内容。窗口创建后由一个共享本地化函数更新静态标签；运行时格式化函数通过当前语言字典生成文字。语言切换复用同一刷新路径重新呈现最近一次内存状态，避免重新扫描会话文件。

现有中文错误、通知和菜单文本纳入字符串键。开发自检中的断言说明可以继续使用英文，因为它们不会出现在用户界面。

## 失败处理

- 所选语言包缺失或损坏：回退英语并保留偏好选择，修复文件后下次启动可恢复。
- 非英语包漏掉普通键：使用对应英语文字。
- 占位符集合与英语不一致：该语言包自检失败，运行时忽略该条翻译并回退英语。
- 英语基础包不可用：终止启动，显示内置双语错误，不打开不完整界面。
- 偏好文件中的语言代码无效：忽略并重新按系统语言选择。

## 验证

现有 `-SelfTest` 增加以下检查：

- 五个 JSON 文件可解析，大小和结构合法。
- 每份语言包的键和格式占位符与英语一致。
- 五种语言均不出现空白界面文字。
- 系统语言映射、无效偏好和英语回退正确。
- 切换语言只改变呈现，不改变令牌、缓存或任务数据对象。
- 中、英、日、韩数字与倒计时格式使用预期单位。

启动器回归继续确认没有可见控制台和残留 `cmd.exe`。发布前同时运行 PowerShell AST 语法检查、敏感信息扫描和安装包文件清单检查。

## GitHub 仓库

只将 `CodexUsageWidget` 目录作为仓库根目录，避免公开外层工作区。仓库设置如下：

- 名称：`codex-usage-widget`
- 可见性：公开
- 默认分支：`main`
- 许可证：MIT
- 版权署名：已登录 GitHub 用户名
- 首发标签：`v1.0.0`

仓库至少包含主脚本、两个启动入口、五份语言包、中英文 README、MIT 许可证、简短贡献说明、安全说明、截图、自检 fixture 和发行说明。不得提交本机偏好、缓存账本、会话记录、备份目录或临时文件。

## README 与宣传

README 首页沿用真实的圆环和详情截图，突出以下事实：

- Windows 桌面悬浮圆环，可拖拽和边缘吸附。
- 鼠标悬浮查看本机观测到的用量、令牌、缓存与任务详情。
- 五种界面语言，可离线切换。
- 不联网，不读取或保存账号凭据。
- 数值来自本机 Codex 会话记录，不是官方账单或账户余额。

新增一张 GitHub 社交分享封面，使用现有真实产品截图和简洁标题，不生成不存在的产品界面。仓库描述和主题标签使用简洁英文以便搜索；README 和发行说明同时提供中文入口。

准备三份可复制宣传文案：中文长版、中文短版和英文版。文案只陈述已验证功能，不使用“官方”“精确账户余额”等误导性表述。

## 发布流程

1. 完成语言包、许可证和开源文档。
2. 运行完整自检、启动器回归、语法检查与隐私扫描。
3. 初始化 `main` 分支并提交经过确认的项目文件。
4. 用户完成 GitHub CLI 登录后创建公开仓库并推送。
5. 配置仓库描述、主题标签和社交分享图。
6. 生成可直接解压运行的 ZIP，创建 `v1.0.0` Release 并上传。
7. 打开线上 README、发行页和下载链接进行最终核验。

## 完成标准

- 五种语言可即时切换并在重启后恢复。
- 所有用户可见文本均由语言系统控制，启动兜底错误除外。
- 原有统计、自检、拖拽、吸附和无窗口启动行为不回归。
- GitHub 仓库公开可访问，README 截图正常，Release 附件可以下载并通过本地自检。
- 仓库不含个人数据、绝对路径、会话记录或密钥。
